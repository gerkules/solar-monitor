# collector нативно на Raspberry Pi 1 (ARMv6)

Docker-стек целиком на ARMv6 не поднимается: нет образов python:3.12-slim / influxdb / grafana.
Здесь — только collector + его встроенный Web UI (live-состояние, настройки, АКБ).
Истории и графиков не будет (InfluxDB/Grafana не устанавливаются).

## Установка
    sudo bash deploy/pi/install-pi.sh
Затем отредактировать `/opt/solar-monitor/.env` (инвертор, MQTT) и:
    sudo systemctl restart solar-collector

## Ключевой момент
`pydantic<2` — иначе pip тянет pydantic-core (Rust) и сборка падает на ARMv6.
Проект pydantic напрямую не использует, работает и на v1.

## Производительность (замер на Pi 1, 512 МБ)
| POLL_INTERVAL | CPU | RSS |
|---|---|---|
| 5 (дефолт) | ~22% | 26 МБ |
| 10 | ~3% | 26 МБ |

Рекомендуется 10 с и больше.

## USB-RS232 / RS485 (физический кабель к инвертору)

Драйверы `ch341`, `pl2303`, `ftdi_sio`, `cp210x` уже в ядре Raspbian — ставить ничего не нужно.
Адаптер появится как `/dev/ttyUSB0`, стабильное имя — в `/dev/serial/by-id/`.

Скрипт установки добавляет пользователя `solar` в группу `dialout`, а юнит — `SupplementaryGroups=dialout`.
Без этого коллектор не откроет порт (Permission denied) и UI покажет «нет связи» при живом кабеле.

Настройка — в UI, страница «Подключение»:
1. Способ подключения → «Физический USB-RS232 / RS485»
2. Порт — выбрать из выпадающего списка (`/dev/serial/by-id/...` предпочтительнее: не меняется)
3. Скорость 2400 (стандарт PI30; у части моделей 19200)
4. Кнопка «Проверить связь»: покажет АКБ В / сеть В / нагрузку Вт / серийный номер и задержку

Транспорт можно менять в UI без правки `.env` — выбор хранится в `/data/connection.json`.

### Что важно при передаче Pi другу
- Инвертор должен быть **PI30-совместимым** (Voltronic/Axpert/Must с протоколом PI30).
  Growatt, Deye, Solis и прочие со своим протоколом — не подойдут.
- Кабель: USB-RS232 к порту RS232 инвертора; у части моделей RS232 выведен на RJ45 —
  нужна правильная распиновка (в комплекте с инвертором).
- Скорость по умолчанию 2400 8N1; если «нет ответа на QPIGS» — проверить 2400/19200.
- Полезно сразу поменять пароль UI (`AUTH_USER`/`AUTH_PASSWORD` в `.env`), иначе панель
  открыта всем в сети — коллектор пишет об этом предупреждение в лог.
