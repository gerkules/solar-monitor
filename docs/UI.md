# Веб-интерфейс

`http://<host>:8080/` — SPA без сборки и без CDN: всё (шрифт Exo, uPlot) лежит в контейнере.

## Навигация

Верхнее меню: **Обзор · Сеть · Энергия · Графики · Настройки**.
В «Настройках» появляется подменю: **Инвертор · АКБ · Подключение · Автоматизация · Коды · Уставки**.
Прямые ссылки (`#/battery`, `#/codes`) работают и подсвечивают нужный пункт.

## Страницы

| Страница | Содержимое |
|---|---|
| **Обзор** | 4 gauge (PV/нагрузка/АКБ/сеть), схема потоков (иконки панели, дома, ЛЭП, АКБ с заливкой по SOC, инвертор — как ваш), «Энергия за сегодня» с прогнозом, «Массивы PV» (если второй MPPT), «Состояние» |
| **Сеть** | наличие сети, напряжение/частота/мощность, импорт за сутки, подробная таблица |
| **Энергия** | кВт·ч за сутки / 7 / 30 дней по источникам |
| **Графики** | «Обзор» (PV+нагрузка+сеть) с кнопками серий, затем отдельные графики по метрикам; период 1ч…30д; выделение области синхронизирует все графики; экспорт PNG/CSV |
| **Инвертор** | все метрики `QPIGS` и паспорт из `QPIRI` |
| **АКБ** | протокол BMS инвертора (10 протоколов + флаги + журнал кодов), источник данных АКБ (67 позиций), состояние батареи, уставки напряжений |
| **Подключение** | выбор транспорта, найденные порты, «Проверить связь», «Применить» на лету |
| **Автоматизация** | правила (условие → действие), тест уведомлений |
| **Коды** | справочник: BMS, ошибки, предупреждения, параллельные + быстрые действия |
| **Уставки** | 10 параметров с записью и проверкой |

## Особенности

* **Живые данные** — SSE (`/api/v1/stream`), страница обновляется без перезагрузки.
* **Тема** — светлая по умолчанию, тёмная кнопкой 🌙/☀️ в шапке; выбор запоминается, графики
  перерисовываются в цветах темы. Жёстко: `?theme=dark|light` (для киоска/скриншотов, без анимации).
* **Язык** — по языку браузера (русский/английский/греческий), переключатель 🌐 в шапке,
  `?lang=ru|en|el`; единицы измерения тоже локализуются.
* **Сайты** — селектор в шапке, если коллекторов несколько; выбор определяет и данные, и уставки,
  и страницу подключения.
* **Индикация проблем** — бейдж `⚠ код 69` / `⚠ нет связи BMS` в шапке и баннер на «Обзоре».
* **Плотность** — на 1440×900 «Обзор» помещается без прокрутки; на телефоне схема переключается
  на вертикальную компоновку, меню переносится (не обрезается).
* **Экспорт** — у каждого графика PNG (с фоном темы) и CSV (`time,<серия>,…`).

## Киоск на планшете/мониторе

```
http://<host>:8080/?theme=dark&lang=el#/overview
```

Можно открыть в полноэкранном режиме браузера; страница сама обновляется по SSE.
