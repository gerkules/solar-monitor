# История

Формат: итерации по возрастанию. Каждая запись — то, что реально сделано и проверено.

## 1. Ядро коллектора
PI30-парсеры (QPIGS/QPIGS2/QPIRI/QMOD/QID/QPIWS), CRC, четыре транспорта (USB-HID, USB-RS232, TCP,
MQTT-сокет), опрос с интервалами, MQTT с SA-совместимыми топиками и HA discovery, InfluxDB,
HTTP API. Проверено на живом инверторе (Axpert 11 кВт, S/N TEST000000000001).

## 2. Уставки с проверкой
Запись 9 параметров PI30 + подтверждение чтением QPIRI (аналог `set_verified`), HA `select`/`number`.

## 3. История и дашборды
Grafana-дашборд (22 панели), генератор дашборда, retention, часовые агрегаты Flux.

## 4. Веб-интерфейс
FastAPI + SPA (без сборки), SSE-обновление, страницы обзор/инвертор/АКБ/сеть/энергия/графики/настройки.

## 5. Правила, уведомления, прогноз
Движок правил (`for_s`, `cooldown`), Telegram/webhook/MQTT, forecast.solar с записью в Influx,
экспорт CSV, backup/restore.

## 6. Мультисайт и авторизация
Retained-состояния по сайтам, реестр сайтов, селектор в UI, HTTP Basic/токен.

## 7. Импорт SolarAssistant (`sa-mqtt`)
Чтение MQTT-выхода SA как источника: маппинг топиков, `total/*` как резерв, проксирование записи
уставок. Проверено на офисном инверторе.

## 8. Мониторинг АКБ (как в SA)
Источник данных АКБ (inverter/emulated/jbd/daly/pylontech/modbus/vedirect/can/voltronic),
каталог 67 позиций с выбором в UI, перекрытие инверторных значений, эмуляция кулонометрией.

## 9. Протокол BMS инвертора + QBMS
10 протоколов (`PBT00…09`), чтение `QBMS` (связь, SOC, лимиты, запреты), коды 60/69/70/71,
баннер, кнопки User/AGM, журнал кодов.

## 10. Авто-откат протокола (opt-in)
Проверка связи после смены протокола, откат при отсутствии связи, восстановление с повторами.
На живом инверторе подтверждено: связь поднимается за 20–30 с.

## 11. Справочник кодов
43 кода из мануала Axpert MAX с рекомендациями и быстрыми действиями; журнал кодов BMS в Influx.

## 12. UI: вид как у SolarAssistant
Светлая тема с палитрой SA, Exo, градиентная шапка, полукруглые gauge, плотность, тёмная тема,
перекомпоновка «Обзора» в две равные колонки.

## 13. Иконки вместо прямоугольников
Панель/дом/ЛЭП/АКБ/инвертор (настенный EASUN-стиль), вариант иконки по `QPIRI`, затемнение подписей
поверх проводов, две панели при двух MPPT, заливка АКБ по SOC + ток и направление.

## 14. Мобильная вёрстка
Отдельная вертикальная компоновка схемы, перенос меню вместо обрезки, компактная шапка.
Проверка — Playwright с device-эмуляцией.

## 15. Подключение в UI
Страница «Подключение»: 4 транспорта, найденные порты, «Проверить связь» (QPIGS+QID+QPIRI),
применение на лету, сохранение выбора.

## 16. Офис отдельно
`?site=<peer>` проксируется на API соседнего коллектора; источник `direct|sa-mqtt` в
`connection.json`; переход с импорта на прямое подключение с мягким перезапуском.

## 17. Графики как в SA
«Обзор» (PV+нагрузка+сеть) с кнопками серий, 14 отдельных графиков, период 1ч…30д, синхронный зум,
экспорт PNG/CSV, запоминание периода, пунктирный прогноз PV.

## 18. Навигация
Верхнее меню сжато до 5 пунктов, «Инвертор/АКБ/Подключение/Автоматизация/Коды/Уставки» —
в подменю «Настройки».

## 19. Локализация
Русский/английский/греческий по языку браузера, переключатель в шапке, локализация единиц.

## 20. Документация
Раздел `docs/` с архитектурой, установкой, конфигурацией, API, MQTT, хранилищем, эксплуатацией,
диагностикой и руководством разработчика.

## 21. Безопасность и смена пароля
HTTP Basic + HTTPS на `API_PORT` (self-signed, `tools/gen-cert.sh`), TLS-aware healthcheck,
`FORCE_HTTPS`/`API_HTTPS_PORT` (HTTP+HTTPS одновременно), креды пира для мультисайта.
Grafana закрыта Caddy (HTTPS + Basic, порт 3443), сам Grafana слушает только localhost.
Смена пароля в UI (PBKDF2-SHA256 в `/data/auth.json`, перекрывает `.env`), `GET/POST /api/v1/auth*`.
Документ `docs/SECURITY.md`.
