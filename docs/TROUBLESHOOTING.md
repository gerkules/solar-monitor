# Известные проблемы и решения

Все пункты — из реальной эксплуатации, с фактами.

## Пустой список «Способ подключения», кнопки не реагируют
**Причина:** браузер держит старый `app.js` (страница новая, обработчиков нет).
**Решение:** в сборке статика версионируется (`?v=<время старта>`), достаточно перезагрузить
страницу. Если правили файлы руками — пересоберите контейнер.

## `device_mode` показывает `0` / `2` вместо `Battery`
**Причина:** на общем UART (инвертор + ESP32 + SolarAssistant) в ответ на `QMOD` приходит чужой
кадр `QPIGS`, CRC у него валидный.
**Решение:** в `pi30.parse_qmod` ответ принимается только если это ровно одна буква режима;
`QID` — только 8–20 alnum. Обновлено, добавлены тесты.

## Мусорные выбросы в истории (например 11 510 Вт на массиве 40 Вт)
**Причина:** склеенный кадр `QPIGS2` с валидным CRC.
**Решение:** проверка `P ≈ U·I` в `parse_qpigs2` + `pi30.sanitize` (диапазоны). В логе:
`QPIGS2: implausible values dropped: pv_power_2`.

## Прогноз PV не отображается
**Причина:** forecast.solar вернул `429` — **12 запросов в час на IP**.
**Проверка:** `curl -s localhost:8080/api/v1/forecast | jq .last_error`.
**Решение:** кэш `/data/forecast.json` + пауза 30 минут; лимит сбрасывается через час.
Не перезапускайте контейнер часто — каждый рестарт раньше тратил запрос.

## InfluxDB 2.x «висит» на Synology
**Диагноз:** процесс в состоянии `D (disk sleep)`, `wchan=wait_on_page_bit_common` — bolt+btrfs.
**Решение:** `docker-compose.synology.yml` (InfluxDB 1.8) + `INFLUX_MODE=1.8` +
`INFLUX_MODE=1.8 python3 tools/make_dashboard.py`. Лучше — держать БД на VDS/mini PC.

## Grafana в crash-loop (Synology)
**Причина:** `/var/lib/grafana` не доступен для uid 472.
**Решение:** `chown -R 472:472 data/grafana`.

## Docker на DSM: `Bind mount failed: … does not exist`
**Решение:** создать каталоги заранее: `mkdir -p data/{influxdb,influxdb-config,grafana,collector}`.

## `apply_setting`: «инвертор отказал (NAK)», хотя значение применилось
**Причина:** на общем UART вместо `(ACK)` пришёл чужой кадр, код принял его за NAK.
**Решение:** `apply_setting` ретраит, пока не получит именно `ACK`/`NAK`; при отсутствии обоих —
честная ошибка.

## После смены протокола BMS нет связи с батареей
**Факт:** инвертор подключает АКБ за **20–30 секунд** после выбора правильного протокола; при
неверном протоколе он **не заряжает** батарею, а на дисплее может быть код 62/69.
**Решение:** подождать 20–30 с; при необходимости выбрать User/AGM; в UI есть «Подтвердить сейчас» /
«Вернуть прежний». Авто-откат (`BATTERY_TYPE_ROLLBACK`) по умолчанию выключен — инвертор
защищается сам.

## Код 69/60/70/71 на дисплее
Это не ошибка, а требование BMS (см. [INVERTER.md](INVERTER.md)): инвертор слушается батареи.
Полный справочник и быстрые действия — страница **Коды**.

## «Нет данных» в графиках, но состояние живое
**Причина:** история пишется только при работающем InfluxDB; `history` вернёт 501, если Influx не
настроен, и 502 при ошибке запроса.
**Проверка:** `curl -s localhost:8080/api/v1/energy?from=-1d` и `docker compose logs influxdb`.

## USB-HID не виден в контейнере
**Проверка:** `ls -l /dev/hidraw*` на хосте, затем `docker compose exec collector ls /dev/hidraw*`.
**Решение:** раскомментировать `devices:` в compose, добавить `group_add: [dialout]`,
пересоздать контейнер (`up -d --force-recreate`).

## MQTT-подписки перестали получать данные
Клиент сам пересобирается при падении цикла; смотрите `mqtt_restarts` в `/healthz`. Если растёт —
проверьте брокер и сеть. `OFFLINE_AFTER` не даёт «дёргаться» статусу при коротких обрывах.

## Caddy: `hashedSecret too short to be a bcrypted password`
**Причина:** Compose подставляет переменные в `env_file`, и `$` в bcrypt-хэше «съедаются»
(остаётся `$2a$14`).
**Решение:** `./tools/set-grafana-proxy.sh '<пароль>'` (экранирует `$` → `$$`) и
`docker compose up -d --force-recreate caddy`. Проверка: `docker exec solar-caddy sh -c 'printf %s "$GRAFANA_PROXY_HASH"' | wc -c` → 60.

## Коллектор просит пароль, а `.env`-пароль не подходит
**Причина:** пароль меняли в UI — он лежит в `/data/auth.json` и перекрывает `.env`.
**Решение:** либо вводите новый пароль, либо удалите файл:
`docker compose exec collector rm /data/auth.json && docker compose restart collector`.

## Офисный сайт: кнопки «Применить» отключены
Это `TRANSPORT=sa-mqtt` — данные импортируются из SolarAssistant. Кнопки включаются, если
переключить сайт на прямое подключение (коллектор перезапустится). Помните: физический USB
доступен только на машине, куда воткнут кабель (на VDS — только TCP-путь).
